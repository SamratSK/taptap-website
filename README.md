Some sites block paste or only listen for real key presses. TapTap types your text in key by key, so it lands in code editors, forms and rich text like you typed it.

## Features

- **Real keystrokes**: autocomplete, validation and editor shortcuts react as they would to you.
- **Human-like rhythm**: adjustable speed, natural variation and pauses after punctuation.
- **Works almost anywhere**: text boxes, rich text editors, and code editors like Monaco, CodeMirror and Ace, including fields inside frames.
- **Keyboard shortcut**: open or hide TapTap on any page with <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd> (<kbd>⌥</kbd><kbd>⇧</kbd><kbd>W</kbd> on Mac).
- **Discreet mode**: the panel fades almost invisible until you hover it, with a visibility slider.
- **Library**: import `.ttlib` files and TapTap loads the matching text on each page.
- **Private**: no servers, no accounts, no tracking. Your text stays in your browser.

## How to use

1. Install TapTap from the Chrome Web Store: https://chromewebstore.google.com/detail/taptap/hmpkahjeocdcmoplhgdccgbpoggaohel
2. Press <kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>W</kbd>, or click the TapTap icon, to open the panel.
3. Press **Select** and click the field you want to type into.
4. Paste your text into the panel and press **Start typing**.

Press **Stop** or <kbd>Esc</kbd> to stop at any time.
