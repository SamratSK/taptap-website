Frequently asked questions

Why not just paste?

Some editors and forms block paste, mangle formatting, or only react to real key presses. TapTap types each character the way a keyboard would, so the page sees normal typing.

Which fields does it work in?

Text boxes, text areas, rich text editors, and code editors like Monaco (VS Code style), CodeMirror and Ace. It also reaches fields inside frames and web components.

Why does Chrome show a debugging bar?

That bar is how Chrome lets an extension send real keystrokes. It appears only while TapTap is typing and closes when it finishes. Pressing Cancel on it stops typing.

Does my text leave my computer?

No. Your text stays in your browser. TapTap has no servers, no accounts and no tracking.

Can I stop it halfway?

Yes. Press Stop or Esc at any time. While it types, the field is locked so stray key presses cannot mix into your text.

Which browsers are supported?

Chrome and Microsoft Edge, and other Chromium browsers that allow Chrome Web Store extensions.
